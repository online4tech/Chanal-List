## قبل تثبيت النسخة

1. تأكد من أن جهازك يعمل بنظام Enigma2 وأن النسخة الاحتياطية متوافقة مع صورة النظام الموجودة عليه.
2. احتفظ بنسخة احتياطية حديثة من إعدادات جهازك وقوائمك الحالية.
3. راجع محتويات الأرشيف وطريقة الاستعادة التي توفرها صورة النظام قبل تطبيقه.
4. لا تستعد نسخة OpenATV على صورة مختلفة إلا بعد التأكد من التوافق؛ فقد تختلف ملفات الإعدادات بين الصور والأجهزة.
5. بعد الاستعادة، أعد تشغيل واجهة Enigma2 بالطريقة المعتادة في صورة النظام، ثم تحقق من ظهور القوائم.

> **تنبيه:** الأرشيف نسخة احتياطية، وليس ملف قنوات XML منفردًا. لا تفكّه فوق مجلدات النظام عشوائيًا ولا تستبدل ملفات إعدادات الجهاز دون نسخة احتياطية.
